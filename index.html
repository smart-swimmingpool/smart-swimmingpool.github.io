Pool Automation in a Smart Way

An Open Source Project to manage your Swimming Pool using Home Automation. 
Control circulation, heating, and monitoring - all from your smartphone.

Get Started Quick Start - 60 Minutes
⚠️

WARNING: 230V Mains Voltage

This project operates with 230V AC mains voltage and should only be built by individuals with basic electronics knowledge. Always use an RCD (residual-current device). This project is not CE/UL certified and not intended for commercial use.

✨ Why Smart Swimming Pool?

Runs on its own

The control logic lives on the ESP32. Circulation and heating keep working without internet, WiFi or a smart home server.

Circulation and solar heating

Timed filter-pump circulation and solar heating with hysteresis. Operation modes: Auto, Manual, Boost and Timer.

Smart home ready

Home Assistant discovers the controller automatically via MQTT Discovery. openHAB and other MQTT systems connect with manual configuration.

Built to be reliable

Settings survive reboots, a hardware watchdog recovers from faults, and the relays stay off while the controller boots.

Easy to operate

Built-in web interface for configuration and control, plus over-the-air firmware updates.

Open and modular

MIT licensed. Start with the controller (electronics ca. 35–55 €) and add monitor, Grafana dashboard or water quality monitor later.

  1. Start Here — pick the path that fits your setup
  2. Quick Start — breadboard setup in 60 minutes, or the detailed Build Guide

  4. Home Assistant or openHAB integration

Everything else is in the full documentation.
